## 📖 Writing — *Data Analyst → AI Solution Engineer* 시리즈

분석가가 AI 시대에 살아남는 방법을 3부작으로 연재했습니다.

- **1편** — *우리 회사가 내 직무를 대체하는 AI를 만들었다*

- **3편** — *AI 시대에 대체되지 않는 것: 책임 · 관계 · 90%를 위한 다리*
