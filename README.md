### Hi, I'm Jinwoo 👋

이벤트 데이터와 AI 도구를 만듭니다. 지금은 [ThinkingAI](https://thinkingai.io/kr/) 한국팀에서 게임·이커머스 고객의 분석 환경을 설계하고, 팀이 매일 쓰는 내부 도구를 직접 만들어 운영합니다.

불편한 일이 반복되면 도구로 바꾸는 편이고, 구현은 Claude Code 같은 코딩 에이전트와 함께, 설계와 검증 기준은 제가 쥐고 갑니다.

#### 요즘 만드는 것

- **다국어 문구 관리** — 여러 사내 프로젝트의 화면 문구를 ko·en·ja·zh 로 한곳에서 관리하고, 코드의 사전 파일과 3자 비교로 동기화. CLI·MCP 로 에이전트도 같이 씁니다.
- **MCP 도구 모음** — 분석 솔루션 문서·이벤트 설계·분석 API 를 에이전트가 쓰는 MCP 서버로. 일부는 npm 에 공개: [td-docs-mcp](https://www.npmjs.com/package/td-docs-mcp) · [td-taxonomy-mcp](https://www.npmjs.com/package/td-taxonomy-mcp) · [td-analytics-mcp](https://www.npmjs.com/package/td-analytics-mcp)
- **Crew** — 팀원들의 Claude Code 작업을 한 화면에서 보고 이어 가게 하는 macOS 앱 (Swift)
- **고객 헬스 포털** — 분석 솔루션·CRM·메신저 데이터를 모아 매일 지표·알림·브리핑으로
- **커머스 데이터 커넥터** — 쇼핑몰 웹훅·리포트 API 를 분석 솔루션으로 보내는 멀티 테넌트 수집 서비스

> 회사에서 만드는 것들은 비공개 저장소라 설명만 적어 둡니다.
